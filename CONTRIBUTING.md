# Berkontribusi

Terima kasih sudah membantu memperbaiki katalog. Kamu boleh membaca dan menjalankan kode tanpa akun. Untuk mengajukan usulan di repositori ini, masuk ke GitHub dan [buat issue ide baru](https://github.com/SammdoDev/Ruang-Peluang/issues/new?template=ide-baru.md). Formulir di situs dapat membuat draf issue terisi, tetapi pengiriman tetap memerlukan tindakanmu di GitHub.

Untuk setiap ide baru, berikan:

1. Nama dan ringkasan model bisnis, kategori, pelanggan, model monetisasi, dan kompleksitas.
2. Contoh operator luar negeri beserta halaman resmi berawalan `https://`.
3. Fakta yang bisa dibuktikan dari halaman itu; hindari angka pertumbuhan, klaim “pertama”, atau statistik tanpa sumber.
4. Hipotesis Indonesia yang diberi label sebagai asumsi, termasuk pesaing lokal yang perlu diteliti.
5. Uji kecil yang terukur dan risiko utama.

Jangan menyalin artikel atau foto pihak ketiga ke dalam repositori. Koreksi sumber, duplikasi ide, tautan rusak, dan kritik atas skor awal juga diterima lewat issue.

Untuk perubahan kode atau data, fork repositori, buat branch, jalankan `npm run check` dan `npm run build`, lalu kirim pull request dengan penjelasan singkat. Ide yang diusulkan tidak otomatis dipublikasikan; maintainer meninjau sumber dan redaksinya sebelum menggabungkan.
